# Generic Image Puzzle

משחק סטטי שמאפשר להעלות כל ציור/תמונה ולהפוך אותו לפאזל בדפדפן.

## מה יש במשחק
- העלאת JPG / PNG / WEBP
- 3 רמות קושי: 2x2, 3x3, 4x4
- גרירה של חלקים
- אפשרות לחיצה על חלק ואז על משבצת
- רמז
- תמונת יעד חלשה ברקע או ללא רקע
- מסך הצלחה
- ללא backend
- מתאים ל-GitHub Pages

## הפעלה מקומית
אפשר פשוט לפתוח את `index.html` בדפדפן.

## GitHub Pages
1. העלו את `index.html`, `style.css`, `script.js` לריפו.
2. GitHub > Settings > Pages.
3. בחרו Deploy from a branch.
4. בחרו main ו-/root.
5. Save.

כל העיבוד של התמונה קורה מקומית בדפדפן עם FileReader. התמונה לא נשלחת לשרת.
