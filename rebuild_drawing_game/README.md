# בונים מחדש את הציור

משחק פאזל פשוט לילדים, בנוי ב-HTML/CSS/JavaScript בלבד ומתאים ל-GitHub Pages.

## הפעלה מקומית
פתחו את `index.html` בדפדפן.

## העלאה ל-GitHub Pages
1. העלו את כל הקבצים לריפו.
2. ב-GitHub עברו אל Settings > Pages.
3. בחרו Deploy from a branch.
4. בחרו את `main` ואת `/root`.
5. שמרו.

אין צורך בשרת או ב-build.


## תיקון
לוח היעד מציג עכשיו את הציור כולו כרקע רציף, כך שהקווים מיושרים בין כל 9 המשבצות.
